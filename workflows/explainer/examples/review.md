# Review before release

A useful review catches a concrete risk before a draft reaches a customer.

## Follow the draft

The author writes the draft. The reviewer checks the draft against the brief. If a claim is unsupported, the reviewer returns the draft to the author. The author revises it before approval.

## Check the evidence

Before approving a draft, check these three things:

1. Every factual claim has supporting evidence.
2. Every image has permission for the intended use.
3. Every customer detail is necessary and approved for sharing.

## Distinguish a rule from an exception

Keep customer information inside the approved workspace. Public information is an exception only when the owner has explicitly approved publication. An exception is not permission to publish private details.

## Match the tool to the task

Use a checklist when the same checks repeat. Use a conversation when the brief is unclear. A checklist makes routine omissions visible, while a conversation resolves an ambiguous requirement.

## Recap

Review the draft, verify the evidence, and resolve the risk before release.
