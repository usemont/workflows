# Security and data handling

Mont workflows are trusted executable instructions, **not a sandbox**. Review downloaded workflow DAGs, native scripts, child definitions, JSON assets, and prompt text before execution. The asset loader's collection-root containment rule prevents escaping through `$asset`/`$json`; it does not make the other workflow operations sandboxed. Local read-text, workspace, and import operations can access files permitted by the process. Provider nodes can transmit their bound input content to configured endpoints. Treat a collection's requested files and provider-bound data as carefully as a local program's inputs and network requests.

Provider endpoints, protocol, models, and `credentialEnv` names are set in your local configuration, not by this collection. Credentials are read from environment variables; do not put credentials inline in configuration or graph assets, commit a populated secrets file, print a key in logs, or reuse a production key for an unreviewed workflow. Use restricted, short-lived, budget-limited credentials where your provider supports them. HTTPS is required except for intentionally configured loopback HTTP services. An adapter ID such as `haiku` is a logical name and does not select a vendor by itself.

Narration Markdown, scene scripts, word timestamps, proposed visuals, review decisions, and intermediate generated text can appear in durable workflow inputs, outputs, checkpoints, and artifacts. Protect the output directory and decide its retention policy before using confidential content. Provider retention and training policies remain those of each configured service. Replacing an adapter changes who receives content; review every endpoint in the local config.

Provider failures, malformed responses, empty/unmatched transcription, inconsistent WAV formats, unsupported relationships after repair, missing assets, and native rendering failures are surfaced as errors. The collection does not deliberately replace failed narration with silence or infer new audio timestamps from word counts. Optional visual proposals may be rejected in favour of an already validated native scene; that is visible in policy evidence and does not conceal an audio failure.

The source archive is user-supplied material. Prompts constrain model outputs but are not a security boundary against malicious Markdown, prompt injection, or a hostile provider. Do not run untrusted downloaded graph definitions merely because their prompts look harmless. Report vulnerabilities without publishing narration, environment values, private provider responses, or credential-bearing URLs.
